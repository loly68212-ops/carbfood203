تشغيل موقع «كارب الأطعمة» (نسخة آخر نشر) محليًا على Windows
==============================================================

الملف الرئيسي: app.py
أمر التشغيل (نفس أمر النشر): streamlit run app.py --server.port 5000

الخطوات:
1) ثبّت Python 3.11 أو أحدث من python.org (فعّل "Add Python to PATH")
2) افتح CMD داخل هذا المجلد ونفّذ:
     pip install -r requirements.txt
     streamlit run app.py
3) يفتح الموقع على: http://localhost:5000

ملاحظات:
- الذكاء الاصطناعي معطل (AI_SEARCH_ENABLED = False في app.py) —
  لا يحتاج أي مفتاح أو قاعدة بيانات، وتظهر بطاقته برسالة «غير مفعلة حاليًا».
- مع إنترنت تُجلب بيانات الأطعمة من Google Sheets تلقائيًا؛
  بدونه يعمل من foods.xlsx المحلي.
- كل الأقسام تعمل كاملة: البحث، الكارب لكل جرام، البدائل الغذائية،
  وجبتي، حاسبة الملصق الغذائي، جرعات الإنسولين، النصائح، والقائمة الجانبية.
